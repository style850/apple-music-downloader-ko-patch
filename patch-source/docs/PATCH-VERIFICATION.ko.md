# 보안·한국어 EXE 패치 r2 검증 — 2026-11-08

대상은 원본 Apple Music Downloader Native **1.0.3-beta.4 / Windows x64** 및 첫 번째 패치 설치본입니다.
기준 소스: `6adb6703d4f8ef04e08dc0e3e47b57d44c4f1786`.

배포 EXE: `AppleMusicDownloader-1.0.3-beta.4-KO-Security-Patch-r2.exe`  
패치 ID: `amdl-1.0.3-beta.4-ko-security-2`

## 수정 범위

- 앱의 메뉴, 로그인 안내, 오류, 상태, 접근성 문구와 날짜 형식을 한국어로 변경했습니다.
- 실제 설치본에서 상속된 다른 그룹의 읽기 권한이 확인된 runtime 저장소를 보호합니다.
  기존 `data.img`, `control.secret`, `native-runtime.lock`의 내용은 보존하고, 현재 사용자·SYSTEM·관리자만 허용하는 보호된 Windows DACL을 적용합니다.
- 이후 생성하는 세션 파일에도 처음부터 제한된 DACL을 적용하도록 서비스를 수정했습니다.
- r2는 첫 번째 패치에서 runtime 폴더에 상속 플래그 없이 DACL을 설정하던 오류를 고쳤습니다. 그 오류는 기존 cache 하위 파일의 상속 권한을 제거해 빈 DACL(`D:AI`)로 만들었고, 서비스가 runtime 입력을 읽지 못해 `native_bundle_identity_mismatch`로 실패했습니다. r2는 runtime 디렉터리에만 현재 사용자·SYSTEM·관리자의 신뢰된 상속 권한을 적용하고, 민감 상태 파일은 상속되지 않는 보호된 ACL로 유지합니다.
- 원본 4개 파일의 SHA-256을 확인하고 모두 백업한 다음 교체합니다. 교체 실패 시 복구를 시도하며, 백업 파일을 보존합니다. 연결 파일·연결 폴더·다중 하드링크와 알 수 없는 버전을 거부합니다.
- Electron ASAR 무결성 검사를 유지하고 실행 파일에 들어 있는 해당 헤더 해시 64자만 갱신합니다.

## r2에서 직접 확인한 항목

- 패처 회귀 테스트 13개와 `go test ./cmd/amdl-korean-patch ./internal/nativeruntime`가 통과했습니다. 새 runtime 회귀 테스트는 첫 번째 패치의 접근 거부를 재현한 뒤, r2가 cache 입력을 다시 읽을 수 있게 하면서 민감 파일 바이트를 보존하는지 확인합니다.
- payload 준비 Node 테스트 3개가 통과했습니다.
- **최종 r2 EXE 자체**를 별도 설치 파일 복사본에서 실행했습니다. 첫 번째 EXE의 오류 재현, r2 업그레이드, 반복 적용, 원본 복구, 새 원본 설치본 적용, cache 입력 읽기 및 세션 바이트 보존이 모두 통과했습니다.
- 실제 설치본에도 r2를 적용했습니다. 교체 대상 파일의 해시가 r2 manifest와 일치하고, 기존 `data.img`와 `control.secret` 바이트가 보존됐습니다.
- 실제 서비스는 r2 적용 전 `starting`에서 `failed / native_bundle_identity_mismatch`로 전환됐고, 적용 후 `starting`에서 `ready`로 전환됐습니다. 검사 과정에서 로그인·다운로드 요청을 제출하지 않았으며, 서비스는 검증 후 정상 종료했습니다.
- 실제 runtime 상태를 읽기 전용으로 검사해 디렉터리 ACL, 민감 파일 메타데이터 및 cache 70개 입력의 해시·읽기 가능 상태를 확인했습니다.
- 실제 앱 화면을 다시 열어 한국어 메인·설정 화면, `Windows 네이티브 서비스 · 준비됨`, `로그인 확인됨`을 확인했습니다. 기존 세션이 복원된 결과이며, 자격 증명을 입력하거나 새 로그인 요청을 제출하지 않았습니다.
- 패키지 Electron 복사본에서 변경된 ASAR의 무결성 검사가 통과하고 시작 화면과 메인 화면이 로드되는 것을 확인했습니다. DOM의 한국어 문구/`lang=ko`도 확인했습니다. 이 기존 검증은 서비스를 의도적으로 제외했으므로, 첫 번째 권한 상속 오류를 잡지 못했습니다. 숨겨진 창 캡처는 검게 나왔으므로 전체 레이아웃 시각 검증으로 간주하지 않습니다.
- EXE에는 원본 앱 전체, Apple/Android/QEMU 런타임, 사용자 프로필 또는 실제 세션 자료가 들어 있지 않습니다. 원본 `LICENSE`/`NOTICE` 및 실제 서비스에 포함된 Go 의존성의 라이선스 텍스트를 배포 자료에 보존했습니다.
